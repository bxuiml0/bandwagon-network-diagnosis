## 搬瓦工连不上到底是什么情况？先搞清楚定义

搬瓦工 VPS 连不上，通常只有这几种可能：

1. **VPS 本身没有正常运行**（宕机/关机/系统崩了）
2. **IP 被封**（国内无法访问，国外正常）
3. **SSH 端口被封**（IP 通，但端口走不通）
4. **登录信息填错**（密码/端口/IP 输错了）

第 4 条最蠢，但也最常见。先确认一遍 KiwiVM 面板里的信息是否和你客户端里填的一致。搬瓦工的 SSH 端口**不是默认的 22**，是随机生成的五位数，很多人第一次就在这卡住了。

第 1 条，进搬瓦工后台（Services → My Services），看 VPS 状态是不是 Running。如果不是，先启动。

排除掉这两条，再进行后面的检测。

## 第一步：用官方工具检测 IP 是否被封

搬瓦工在 KiwiVM 控制面板里内置了一个 IP 黑名单检测工具，直接用这个最准。

**检测路径**：登录 KiwiVM → 左侧菜单找到 `Blacklist Check` 或直接在面板里找 `Test Main IP` 按钮，点击开始检测。

IP 检测这步不要跳过。我见过有人端口没被封，IP 也没被封，就是 VPS 进入了休眠状态，重启就好了——直接跳去换 IP 纯属浪费钱。

## 第二步：IP 没被封但还是连不上？检测 SSH 端口

IP 检测通过了，SSH 还是死活连不上，这时候大概率是端口被封。

**检测方法**：打开 `port.ping.pe`，在输入框里按 `IP:端口` 的格式输入你的搬瓦工 IP 和 SSH 端口（注意是英文冒号），点击开始检测。

工具会从全球多个节点（包括中国大陆境内节点）同时去连你的端口，然后给出每个节点的连通结果。

**结果判断**：

| 结果组合 | 含义 | 处理方式 |
|---|---|---|
| 境外全绿 + 境内全红 | 端口或 IP 被封 | 先确认 IP 正常，若 IP 没问题就是端口被封，修改端口 |
| 境外全绿 + 境内全绿 | 端口正常 | 排查其他问题（VPS 状态、登录信息） |
| 境外全红 + 境内全红 | 端口未正常监听 | 检查 SSH 服务是否启动，或 VPS 是否宕机 |
| 境内部分红 + 部分绿 | 端口正常，个别节点网络波动 | 通常无需处理，稍等或换网络试试 |

注意一点：普通的 `ping` 命令**检测不了端口**。ping 只测 ICMP，看不了 TCP 端口状态。要判断端口有没有被封，必须用 TCP 检测工具，`port.ping.pe` 走的就是 TCP 连接。

## 第三步：端口被封了怎么修改 SSH 端口

端口被封之后，SSH 客户端进不去了，但搬瓦工的 KiwiVM 控制面板里有个 **Root shell（VNC）**，可以绕过 SSH 直接操作系统。

**操作步骤**：

1. 登录搬瓦工后台 → Services → My Services → 进入对应 VPS 的 KiwiVM 面板
2. 左侧菜单找 `Root shell – interactive`，点击 `Launch` 进入 VNC 终端
3. 在 VNC 里用账户名和密码登录（注意密码输入时不显示字符，手动敲完回车）
4. 输入以下命令编辑 SSH 配置文件：

bash
vim /etc/ssh/sshd_config


5. 在文件里找到 `Port` 那一行（有可能被注释掉了，带 `#` 开头），修改成一个新的端口号
6. 端口范围是 1–65535，建议选一个 10000 以上的数字，避免和常用服务端口冲突
7. 修改完成后，按 `Esc`，输入 `:wq` 回车保存
8. 重启 SSH 服务：

**Ubuntu/Debian 系统**：
bash
/etc/init.d/ssh restart


**CentOS 系统**：
bash
systemctl restart sshd


9. 记下新端口号，回到 SSH 客户端（XShell/Termius/PuTTY 等），把端口改成新的，重新连接

改完端口之后，记得也在 KiwiVM 面板里同步更新 SSH 端口信息（有些面板会自动检测，有些需要手动改），这样下次查看 VPS 信息时不会看到旧端口造成困惑。

## 搬瓦工为什么会被封 IP 和端口？

说句题外话。

IP 和端口被封，绝大多数情况是使用方式不当触发了自动检测机制。这不是搬瓦工的问题，是使用方的问题。

常见原因包括：流量特征明显、端口暴露时间太长、用了高流量导致 IP 进入黑名单等。

几个习惯能降低被封概率：

- 不要长期使用固定端口，定期换一换
- SSH 端口尽量不要用常见数字（22、8022 这类）
- 按照合理合法的方式使用，不要拿 VPS 做容易被触发的事

## 常见问题 FAQ

**Q：搬瓦工 ping 通了但 SSH 连不上，是什么原因？**

A：ping 通说明 IP 没被封，SSH 连不上大概率是 SSH 端口被封了。用 `port.ping.pe` 检测端口，如果境外通境内不通，就是端口问题。进 KiwiVM 用 VNC 修改端口，换一个新端口就能恢复连接。

**Q：搬瓦工端口被封后能免费换 IP 吗？**

A：不能。搬瓦工已经停止免费换 IP 服务，端口被封的情况下也不需要换 IP，修改 SSH 端口就行，免费操作。只有 IP 本身被封了才需要付费换 IP（$8.79/次）。

**Q：搬瓦工 SSH 端口默认是多少？**

A：搬瓦工不使用标准的 22 端口，每台 VPS 的 SSH 端口是随机生成的五位数端口。具体端口号可以在 KiwiVM 面板的 VPS 详情页面查看，也可以在购买后收到的邮件里找到。

**Q：如何判断是 IP 被封还是端口被封？**

A：先用搬瓦工 KiwiVM 官方工具检测 IP（Blacklist Check），如果 IP 没有被封，再用 `port.ping.pe` 检测端口。两个工具结合用，基本能把问题定位清楚。IP 检测境外通境内不通 = IP 被封；IP 正常但端口检测境外通境内不通 = 端口被封。

**Q：搬瓦工换 IP 之后新 IP 还会被封吗？**

A：官方保证新 IP 不在黑名单里，但后续使用方式不当还是可能被封。换完 IP 建议同时修改一下 SSH 端口，不要继续用被封前的旧端口。
